# Contador de colonias

App web para móvil (instalable) que cuenta unidades formadoras de colonias (UFC) en placas de Petri a partir de una foto.
El análisis se hace en el propio dispositivo con OpenCV.js: las fotos no se envían a ningún sitio.

**No contiene datos personales**: solo la app compilada. Los proyectos y las fotos quedan en cada dispositivo.
